# Supplier Quote Comparison
A small sourcing dashboard that compares supplier quotes by price, delivery date and supplier performance

## What it shows
- Sourcing requests with several supplier quotes
- Landed cost calculated from unit price, quantity and shipping
- Quote eligibility based on MOQ, validity and delivery date
- A recommended quote based on landed cost, lead time and supplier performance
- Quote selection after confirmation
- Dashboard totals for open requests, missing options, selected requests, spend and savings

## Built with
- Node.js
- SAP CAP
- SAPUI5
- SQLite
